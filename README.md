# Triple Triad — Java

Implementação em Java do jogo de cartas **Triple Triad**, desenvolvida como projeto prático para consolidar conceitos de lógica de programação e Programação Orientada a Objetos (POO).

## Sobre o Projeto

O Triple Triad é um jogo estratégico de turnos disputado em um tabuleiro **3x3**. Cada carta possui quatro valores numéricos (topo, base, esquerda e direita) e o objetivo é posicionar cartas no tabuleiro para capturar as cartas adjacentes do adversário que possuam valores menores nos lados em contato, vencendo quem terminar a partida com mais cartas sob seu domínio.

## Funcionalidades

- Criação e gerenciamento de baralhos e cartas com atributos direcionais;
- Tabuleiro 3x3 dinâmico com exibição do estado atual a cada rodada;
- Lógica de comparação de valores adjacentes e captura automática de cartas;
- Alternância de turnos entre jogadores e contagem de pontuação;
- Verificação de fim de partida e declaração do vencedor.

## Conceitos e Tecnologias

- **Linguagem:** Java (JDK 17+)
- **Paradigma:** Programação Orientada a Objetos (Classes, Encapsulamento, Métodos e Composição)
- **Estruturas:** Matrizes bidimensionais, listas/arrays e estruturas de controle de fluxo
